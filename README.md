#  Student Placement Analytics Dashboard

An interactive **one-page Power BI dashboard** developed to analyze student placement outcomes, starting salaries, academic performance, internships, certifications, projects, and skill-related factors.

The dashboard provides a consolidated view of student placement data and allows users to explore the results using interactive filters.

---

##  Project Overview

The **Student Placement Analytics Dashboard** analyzes 50,000+ student placement records to understand placement performance and identify patterns across different academic, professional, and skill-related factors.

The dashboard was designed as a **single-page analytical report**, allowing users to view important KPIs and visual insights in one place.

---

##  Business Problem

Placement data contains valuable information about students' academic performance, skills, internships, projects, and career outcomes.

The objective of this dashboard is to provide an easy-to-use analytical view that helps answer questions such as:

- How many students were placed?
- What is the average starting salary?
- What is the average CGPA and age of the students?
- How does starting salary vary across different majors?
- How are placements distributed across majors?
- How do internships and certifications relate to placement outcomes?
- How do teamwork, projects, and problem-solving skills differ between placed and non-placed students?
- How do student characteristics affect placement analysis?

##  Data Analytics Workflow

### 1. Data Collection
Collected student placement data containing academic, demographic, skill, internship, project, and placement information.

### 2. Data Cleaning
Prepared and cleaned the dataset by checking data types, missing values, duplicates, and data consistency.

### 3. Data Transformation
Used Power Query to transform the data into a format suitable for analysis.

### 4. Data Analysis
Analyzed placement outcomes, salary, academic performance, internships, certifications, and student skills.

### 5. KPI Development
Created measures to calculate important placement and salary metrics.

### 6. Dashboard Development
Built a single-page interactive Power BI dashboard using KPI cards, charts, slicers, and filters.
